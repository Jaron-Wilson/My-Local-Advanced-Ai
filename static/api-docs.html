Chatbot API Documentation

This documentation describes the API endpoints for the AI chatbot with tool capabilities.

API Endpoints

POST /api/chat

Process a chat request and return the response, with optional streaming support.

Request Body

{
  "messages": [
    {"role": "user", "content": "What's the weather in London?"}
  ],
  "stream": true,
  "temperature": 0.2
}

Parameters

Name Type Required Description
messages Array Yes Array of message objects in OpenAI format
stream Boolean No Whether to stream the response (default: true)
temperature Number No Sampling temperature (default: 0.2)

Response

If streaming is enabled, the response will be a Server-Sent Events stream. Otherwise, it will be a JSON object.

// Streaming response format (each event):
data: {"content": "The weather in London is "}
data: {"content": "currently cloudy with a temperature of "}
data: {"tool_calls": [{"index": 0, "id": "call_abc123", "function": {"name": "get_weather", "arguments": "{\"location\": \"London\"}"}}]}
data: [DONE]

// Non-streaming response format:
{
  "response": "I'll check the weather in London for you.",
  "tool_calls": [
    {
      "id": "call_abc123",
      "type": "function",
      "function": {
        "name": "get_weather",
        "arguments": "{\"location\": \"London\"}"
      }
    }
  ]
}
POST /api/tool/execute

Execute a specific tool with the provided arguments.

Request Body

{
  "tool": "get_weather",
  "args": {
    "location": "London"
  }
}

Parameters

Name Type Required Description
tool String Yes Name of the tool to execute
args Object Yes Arguments for the tool

Response

{
  "result": {
    "temperature": "15°C",
    "conditions": "Partly cloudy",
    "humidity": "75%",
    "wind": "10 mph SW"
  }
}
POST /api/image-search-override

Handle image search override confirmation.

Request Body

{
  "query": "sunset over mountains",
  "override": true
}

Parameters

Name Type Required Description
query String Yes Search query for images
override Boolean Yes Whether to override existing images

Response

{
  "result": {
    "images": ["image1.jpg", "image2.jpg"],
    "message": "Images downloaded successfully"
  }
}

Available Tools

  • get_current_time

    Gets the current time.

    Arguments: None

  • get_current_date

    Gets the current date.

    Arguments: None

  • google_search

    Performs a Google search.

    Arguments: query (string)

  • google_image_search

    Searches for images on Google.

    Arguments: query (string)

  • read_webpage

    Reads and extracts content from a webpage.

    Arguments: url (string)

  • get_weather

    Gets current weather for a location.

    Arguments: location (string)

  • get_weather_forecast

    Gets weather forecast for a location.

    Arguments: location (string)

  • generate_image

    Generates an image using AI.

    Arguments: prompt (string), negative_prompt (string, optional), steps (int, optional), width (int, optional), height (int, optional)

  • open_saved_image

    Opens a saved image.

    Arguments: filename (string)

  • open_file

    Opens and reads a file.

    Arguments: filepath (string)

  • list_files

    Lists files in a directory.

    Arguments: directory (string)

  • download_file

    Downloads a file from a URL.

    Arguments: url (string), filename (string, optional)

  • move_file

    Moves a file to a new location.

    Arguments: source (string), destination (string)

  • copy_file

    Copies a file to a new location.

    Arguments: source (string), destination (string)

  • delete_file

    Deletes a file.

    Arguments: filepath (string)

  • rename_file

    Renames a file.

    Arguments: old_path (string), new_name (string)

  • analyze_file

    Analyzes a file and provides information about it.

    Arguments: filepath (string)

  • what_is_this_image

    Analyzes and describes the content of an image.

    Arguments: image_path (string)
